# Final checklist

Run it after `render.py` reports no errors. Every answer should be "yes".

## Truth
- [ ] The logo on the board is the real file, unaltered except for single-color masks.
- [ ] Every color, font and graphic device is in the brand's material or traced to it in the brief.
- [ ] All copy is the brand's own, or visibly labeled as an example.
- [ ] No invented metrics, testimonials, client names, prices or people.
- [ ] Conflicts between the request and the brand are written in the brief.

## Content
- [ ] The cover says whose identity this is and what the board is.
- [ ] The logo block shows the variants the brand really has.
- [ ] Clear space uses a unit taken from the logo, drawn and labeled.
- [ ] Misuses are built from the real logo.
- [ ] Each color has a role, a code, a contrast ratio if it is a text color, and a live use.
- [ ] Type specimens use real sentences and show a size scale.
- [ ] Applications are different sizes and kinds, built from the system.

## Craft
- [ ] No numbered labels over titles, no one-sided color stripes, no three identical cards.
- [ ] No gradient text, glow, glassmorphism or emoji icons; one icon family.
- [ ] Neutrals are tinted; no pure black or white.
- [ ] Blocks differ in width and surface; one region carries full color.
- [ ] Nothing a reader needs is under 13 px on the 2400 px canvas.
- [ ] Every crop looks aligned and nothing touches an edge.
- [ ] In `sweep.png` (65 %), each block is recognizable without reading.

## Files
- [ ] `render.py`: zero errors; warnings understood and either fixed or reported.
- [ ] The PDF is one page and its fonts are the brand's, not fallbacks.
- [ ] The HTML scales to a laptop screen without horizontal scroll.
- [ ] `poster.html`, `poster.png`, `poster.pdf`, `brand-brief.md` and the source are delivered.
